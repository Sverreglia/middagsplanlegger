# Middagsplanlegger

En enkel Spring Boot-applikasjon for å vise informasjon om middager.

## Teknologier

- Kotlin
- Spring Boot
- Gradle
- Thymeleaf

## Kom i gang

### Forutsetninger

- Java 25 eller nyere

Gradle er inkludert gjennom Gradle Wrapper, så du trenger ikke å installere Gradle separat.

### Kjør applikasjonen

Klone prosjektet og gå inn i prosjektmappen:

```bash
git clone https://github.com/Sverreglia/middagsplanlegger.git
cd middagsplanlegger
```
